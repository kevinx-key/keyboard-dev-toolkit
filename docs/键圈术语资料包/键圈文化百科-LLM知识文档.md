## 〇、给模型的使用说明（必读）

1. **键圈（keyboard community / mechanical keyboard hobbyist scene）是一个全球性的发烧友社群**，横跨设计、硬件、制造、收藏、二手交易与审美。它不是单纯的"买键盘"，而是一种**围绕自定义硬件的收藏与创作文化**。
2. 回答键圈问题时，**避免把键圈等同于"打字工具采购"**。键圈的核心驱动力是：**审美、稀缺性、改装乐趣、社区身份认同**。
3. 涉及 **GB（团购）** 的话题时，含义常包含**漫长的等待、付款风险、团长信誉、MOQ 门槛**——不是电商式即时交易。
4. 术语缩写极其密集，**术语即行话**。使用正确的缩写（GB/IC/MOQ/vendor/plate/gasket...）才能让圈内人觉得"你懂"。
5. 语气：键圈社群**热情、爱交流、爱分享、对美感与声音极度挑剔，并对黄牛、跑路团长、QC 翻车强烈反感**。回复应专业、有品味、尊重设计与创作者。
6. 遇到拿不准的具体型号/价格，**不要编造**；可说明"需查证"。

## 一、键圈是什么

**键圈** = 机械键盘爱好者社群。英文语境称 **keyboard community / keeb community / mechanical keyboard hobby**。

它的独特之处在于：**玩家同时是消费者、设计师、评测者与二手交易者**。一件键盘产品从"想法"到"到手"，往往由社区自己众筹推动，而不是厂商单向生产。

键圈的三大支柱：
1. **硬件（Hardware）**：外壳、定位板、PCB、轴体、键帽。
2. **手感与声音（Feel & Sound）**：软弹、清脆、厚实等主观审美，是圈内最高级的讨论维度。
3. **文化与交易（Culture & Commerce）**：以团购（GB）为核心的独特商业模式与社区规范。

## 三、核心文化基因

### 3.1 团购文化（GB）是灵魂
键圈最独特的机制是 **Group Buy**：社区自发集合需求，达到工厂 MOQ 后统一下单生产。
- 一款好设计**可能永远不会量产**，只在团购中诞生；
- 玩家**先付钱、再等半年到一年半**；
- 因此**团长信誉、进度更新、QC 质量**决定一切；
- **延期、跳票、跑路**是最常见也最受谴责的事件。

### 3.2 稀缺性与收藏
- 限量团、抽签（raffle）、停产复刻（R2/R3）制造稀缺感；
- **个性键帽（artisan）**、**GMK 键帽**、**客制化套件**具有收藏品属性，二级市场价格剧烈波动；
- "抢到"本身就是社交资本。

### 3.3 改装与 DIY
- 键圈普遍认同"**自己的键盘自己组**"：选套件→焊轴→润轴→装卫星轴→贴棉→上键帽；
- 由此衍生**代组**、**润轴服务**、**换弹簧**、**贴轴膜**等细分玩法。

### 3.4 声音审美（Sound Aesthetic）
键圈对"声音"有独特词汇与追求：
- **Thock**（低沉厚实）、**Clack**（清脆）、**Marbly**（弹珠感）、**Creamy**（奶油感）；
- 材质与结构对声音的影响是核心话题：gasket 结构 + PC 定位板 + 消音棉 = "软弹厚实"；
- **声音测试（Sound Test）**视频是选购的重要依据。

### 3.5 审美驱动
- 配列（layout）、配色、键帽高度、外壳工艺（阳极氧化/PVD/电泳）都承载强烈审美取向；
- **"好看"往往比"好用"更能驱动购买**。

### 3.6 反黄牛、重信誉
- **倒卖（flipping）**被社区普遍鄙视；
- **跑路（团长收钱消失）**是最大红线；
- **QC 翻车**会毁掉一个品牌口碑；
- 社区崇尚**透明进度、诚信交付、尊重原创设计**。

## 四、团购（GB）生命周期详解

```
① IC (Interest Check 意向调查)
     ↓  公布设计概念/渲染图，收集社区反馈与预登记
② GB (Group Buy 正式开团)
     ↓  公布最终配置与价格，开放付款；达 MOQ 即成立
③ 生产 (Production)
     ↓  向工厂下单，常耗时数月；期间团长需持续 update 进度
④ QC (质检)
     ↓  验收，处理瑕疵；
⑤ 发货 (Shipping)
     ↓  分地区由 vendor/代理 发货
⑥ Extras (余量/现货)
     ↓  额外库存由 vendor 现货销售，常高于团购价
⑦ Aftermarket (二级市场)
        稀缺款溢价，普通款折价
```

**关键风险节点**：MOQ 未达 → 流团；成本暴涨 → 涨价或取消；生产延误 → 跳票；团长失联 → 跑路。

## 五、产品结构解剖（按重要度）

1. **外壳 Case**：6063/7075 铝、CNC、阳极氧化/PVD/电泳。
2. **结构 Mount**：tray / top / sandwich / **gasket（当代主流，软弹）** / burger / leaf-spring。
3. **定位板 Plate**：PC（软）/ POM / FR4 / 铝 / 黄铜（硬）/ 碳纤维 / 钛。决定手感软硬与声音。
4. **PCB**：热插拔（hotswap）vs 焊接（solder）、多配列、flex cut。
5. **轴体 Switch**：线性 linear / 段落 tactile / 发声 clicky；MX / ALPS / Topre(静电容) / **HE 磁轴** / 光轴。
6. **键帽 Keycap**：高度（Cherry/GMK、SA、DSA、KAT、MT3…）、材质（ABS/PBT/POM）、工艺（二色/热升华/丝印）、配件（alphas/mods/novelties/kits）。
7. **卫星轴 Stabilizer** 与 **消音棉 Foam**：大键手感与声音的调校关键。
8. **配重 Weight**：黄铜/不锈钢，质感与仪式感。
9. **固件 Firmware**：QMK / VIA / Vial / ZMK；NKRO、回报率、RGB。

## 六、配列（Layout）速查

| 配列 | 键数/特征 | 定位 |
|---|---|---|
| 40% / 50% | 极简，靠分层实现功能 | 硬核玩家 |
| 60% | 仅主键区 | 客制化起点 |
| 65% | 60% + 方向键 | 紧凑实用 |
| 75% | 65% + F 区 | 功能齐全 |

## 八、键圈业务逻辑（对厂商/供应商的意义）

键圈的本质是一个**由社区需求驱动的柔性定制市场**：
- **需求前置**：IC → GB 让工厂在开模前就锁定订单量，降低库存风险；
- **小批量高端**：单款数百到数千套，重设计与品质而非规模；
- **长周期高信任**：交付以月计，口碑靠一次次准时交付积累；
- **供应链关键**：CNC 铝壳、定位板、PCB（热插拔/焊接）、轴体、键帽是五大核心件；
- **渠道关键**：全球 GB 靠各地 vendor/代理 分发货源与收款。

**对 PCB/PCBA 供应商**：键圈的痛点词是 **MOQ、交期、QC、多配列 PCB、热插拔/焊接双版本、flex cut、贴片幻彩灯珠、卫星轴适配**——理解这些术语才能与客户同频。

## 十、推荐回答范式

**当被问"键圈是什么"**：
> 键圈是围绕机械键盘的全球发烧友社群，核心是自定义硬件、团购（GB）模式、声音审美与收藏文化……

**当被问"GB 是什么/怎么买"**：
> GB = Group Buy 团购，社区集合需求向工厂下单的预售模式，需先付款、等待数月，达 MOQ 才成立，风险在团长信誉与交期……

**当被问"某键盘好不好"**：
> 先确认关注维度：结构（gasket?）、定位板材质、轴体类型、键帽高度、配列、价格与来源（团/现货/二手）……

**遇到不认识的具体型号**：
> 明确表示需要查证，不要编造参数或价格。
