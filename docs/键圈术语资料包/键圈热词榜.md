### 读法
- **GB / IC / MOQ** 是语料绝对高频词，说明团购机制是键圈讨论主轴。
- **GMK / SA / DSA / PBT / ABS** 高频，说明键帽换装是社区第一日常话题。
- **TKL / ISO / ANSI / WKL** 高频，说明配列选择与不同地区需求是长期争论点。
- **PCB / MX / QMK** 高频，说明硬件与固件是玩家深度参与的技术层。
- 大量 IBM/SSK/AEK/X G80 类词高频，说明**复古键盘文化**在键圈占有重要地位。
