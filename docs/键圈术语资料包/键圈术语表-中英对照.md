## 行业机制

| 英文 / 缩写 | 中文 | 释义 | 代表什么 |
|---|---|---|---|
| **GB · Group Buy** | 团购/开团 | 社区自发组织的预售模式：团长发布设计→IC收集意向→达MOQ后向工厂下单→生产→全球发货，全程常需6-18个月。 | 客制化键盘最核心的商业模式，决定了整个圈子的交易节奏与风险结构。 |
| **IC · Interest Check** | 意向调查 | GB前的调研阶段，团长公布设计概念与渲染图，收集社区反馈、投票与预登记，用于判断需求与定价。 | 产品能否立项的风向标；IC热度直接决定后续GB是否开得起来。 |
| **MOQ · Minimum Order Quantity** | 最小起订量 | 工厂/厂家要求的最低订单数量，未达标则可能流产、涨价或延期。 | GB能否成团的红线；很多好设计因达不到MOQ而夭折。 |
| **Vendor** | 代理商/经销 | 经团长授权、负责特定地区(如EU/NA/SEA)收款与发货的合作商家。 | 降低跨境物流与关税门槛，是GB全球化交付的关键角色。 |
| **Proxy** | 代理/代购 | 帮助无法直连团购的地区用户代下单、代收、代发的个人或商家。 | 解决支付与物流壁垒，但也带来信任与加价问题。 |
| **Raffle** | 抽签 | 热门GB用随机抽签分配购买资格，防止服务器秒崩和黄牛。 | 稀缺性的象征，被抽中约等于中奖。 |
| **FCFS · First Come First Serve** | 先到先得/抢购 | 按下单先后顺序售卖，先抢到先得，常在几分钟内售罄。 | 考验网速与手速，热门款秒空。 |
| **Extras** | 余量/加购 | GB结束后额外生产的备用库存，通常在vendor处现货销售。 | 没赶上GB的补救渠道，但价格常高于团购价。 |
| **In-stock** | 现货 | 不等团购周期，直接购买即发货的销售形式。 | 与GB相对，交付快但选择性少、多为量产款。 |
| **Pre-order** | 预售 | 提前下单、后续生产的销售形式，介于GB与现货之间。 | — |
| **B-stock · B品** | 瑕疵品/次品 | 存在轻微外观或工艺瑕疵但功能正常的正品，折价出售。 | 性价比玩家的捡漏渠道。 |
| **QC · Quality Control** | 质检 | 出厂前的质量把控；跳票、瑕疵率高会引发社区公愤。 | QC翻车是GB口碑崩塌的头号原因。 |
| **Deposit** | 定金 | 下单时先付的部分款项，常见50%，尾款于发货前结清。 | — |
| **Invoice** | 账单/付款通知 | 团长或vendor发出的付款请求，通常有付款截止日。 | 逾期未付视为放弃购买资格。 |
| **Round / R1 / R2** | 第几期/复刻 | 同一产品多次开团的编号，R2=第二次复刻。 | 火爆款复刻(重开团)是社区长期呼声。 |
| **TBD · To Be Determined** | 待定 | 价格、日期等尚未确定，常用于IC阶段。 | — |
| **GB Cancellation** | 团购取消/流团 | 因未达MOQ、成本暴涨或团长跑路而终止，涉及退款纠纷。 | 键圈最大信任风险来源。 |
| **Flipping / Flip** | 倒卖/炒货 | 抢购后高价转售赚差价的行为，社区普遍反感。 | 催生二手溢价与黄牛文化。 |
| **Aftermarket** | 二级市场/二手市场 | GB结束后的转售市场，价格随稀缺度波动。 | — |
| **Group Buy Lifecycle** | 团购生命周期 | IC→GB→生产→QC→发货→Extras 的标准流程链。 | 理解键圈一切话题的时间轴框架。 |

## 结构

| 英文 / 缩写 | 中文 | 释义 | 代表什么 |
|---|---|---|---|
| **Case** | 外壳 | 键盘的外壳，材质常见6063/7075铝合金，工艺有CNC、阳极氧化、PVD、电泳、喷涂。 | 外观、重量、声音的第一决定因素。 |
| **CNC · Computer Numerical Control** | 数控加工 | 用数控机床铣削铝块成型，高端客制化的标准工艺。 | CNC铝壳是高端键盘的身份证。 |
| **Anodized** | 阳极氧化 | 铝表面电解着色工艺，色彩耐久、有金属质感。 | 常见色号如黑、银、蓝、紫。 |
| **PVD · Physical Vapor Deposition** | 物理气相沉积 | 真空镀膜工艺，用于做出镜面金、玫瑰金等金属光泽，耐磨。 | 高端配重/外壳的奢华工艺。 |
| **E-coat / Electrophoresis** | 电泳涂装 | 电泳上色，色彩均匀、可做白色，常用于铝壳。 | — |
| **Mount** | 结构/固定方式 | PCB与外壳/定位板的连接方式，决定手感与声音的核心变量。 | 客制化键盘的'灵魂'。 |
| **Tray Mount** | 托架结构 | PCB直接固定在底壳螺柱上的传统结构，成本低、手感偏硬。 | — |
| **Top Mount** | 上固定 | 定位板固定在上壳，手感统一扎实、声音清脆。 | — |
| **Bottom Mount** | 下固定 | 定位板固定在下壳的结构。 | — |
| **Sandwich Mount** | 三明治结构 | 定位板上下被外壳夹住，结构简单、声音直接。 | — |
| **Gasket Mount** | 垫圈结构/软弹结构 | PCB/定位板通过硅胶或泡棉垫圈悬空固定，手感软弹、声音柔和。 | 当代客制化主流结构，'软弹(gasket)'是核心卖点。 |
| **Burger Mount** | 汉堡结构 | 用O型圈将定位板'夹'在上下壳之间的做法。 | — |
| **Leaf Spring Mount** | 板簧结构 | 定位板通过板簧悬臂支撑，提供弹性。 | — |
| **Integrated Plate** | 一体定位板 | 外壳与定位板一体成型，最硬的结构。 | — |
| **Plate** | 定位板 | 固定轴体的板，材质有PC、POM、FR4、铝、黄铜、不锈钢、碳纤维、钛。 | 材质直接决定手感软硬与声音。 |
| **PC Plate · Polycarbonate** | PC定位板 | 聚碳酸酯，软弹、声音温和，主流热门。 | — |
| **POM Plate** | POM定位板 | 聚甲醛，比PC更硬一点，声音扎实。 | — |
| **FR4 Plate** | FR4定位板 | 玻纤板，硬朗、声音清脆。 | — |
| **Brass Plate** | 黄铜定位板 | 极硬、声音高亢明亮。 | — |
| **PCB · Printed Circuit Board** | 电路板 | 键盘主板，分热插拔版与焊接版。 | 键圈讨论的核心硬件之一。 |
| **Hotswap** | 热插拔 | 用热插拔座(Kailh等)免焊接换轴，插拔即换。 | 降低玩轴门槛，量产键盘标配趋势。 |
| **Solder PCB** | 焊接版PCB | 轴体需焊接到PCB，手感一致性更好、更可靠，客制化传统主流。 | — |
| **Multi-layout** | 多配列支持 | 一块PCB支持多种配列(ANSI/ISO/分裂空格等)，用跳线/双焊盘实现。 | — |
| **Flex Cut** | 开槽/柔性切割 | PCB上开槽以提升弹性，常与gasket结构搭配；1.6mm non-flex cut=无开槽。 | — |
| **Foam** | 消音棉 | 填充空腔以改变声音，分Case foam(底棉)、Plate foam(夹心棉)、PE foam。 | 调音的核心道具。 |
| **Gasket** | 垫圈 | 硅胶/泡棉条，用于gasket mount的弹性支撑。 | — |
| **Dampening** | 减震/消音 | 泛指各类减震消音处理。 | — |
| **Weight** | 配重 | 增加键盘重量与质感的金属块，材质有黄铜、不锈钢、铜、钨。 | 高端键盘'沉甸甸'的象征，常刻有品牌/序号。 |
| **Stabilizer** | 卫星轴 | 大键(空格/Shift/Enter等)的平衡机构。 | 大键手感(是否'肉'、'晃'、'响')是键盘好坏的关键评判点。 |
| **Screw-in / Clip-in** | 螺丝固定/卡扣固定 | 卫星轴固定方式，螺丝固定更稳、更易调。 | — |
| **Dielectric Grease** | 绝缘硅脂 | 常用作卫星轴润滑剂。 | — |
| **Standoff** | 铜柱 | 支撑PCB与外壳的支柱。 | — |
| **Typing Angle** | 打字倾角 | 键面倾斜角度(如6°/7°/8°)，影响打字舒适度。 | — |
| **Front Height** | 前高 | 键盘最前端离桌面高度，越低越舒适，是玩家重点关注参数。 | — |
| **Wrist Rest** | 掌托/腕托 | 支撑手腕的配件，提升长时间打字舒适度。 | — |
