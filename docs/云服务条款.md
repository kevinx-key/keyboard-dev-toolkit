# 云服务条款

> 版本 v1.0（2026-10-11）· 面向用户 · 公开
> 适用范围：Keyboard Dev Toolkit 提供的**在线服务**（高级 2D 几何、STP 装配 / 3D 导出、模型下载），域名 `https://starthock.com`。
> 对应内部要求：§G-C5（云 API ToS）。
> 本页为产品说明；正式条款生效前需经**法务确认**。

---

## 1. 服务范围

- 本在线服务提供**高级几何**与 **STP 装配**能力：碰撞体积干涉预警、FL / 板载卫星轴开孔与钢丝间距、高精度 / 异形 DXF 导出、STP 装配 / 3D 导出、以及相关模型下载。
- 基础能力（KLE 解析 / 渲染 / 编辑、矩阵、简单矩形 PCB / 定位板）**在本地运行**，不属于本在线服务的范围。
- 在线服务**可能受限流、维护、容量或上游原因而延迟、降级或中断**，不保证 100% 可用；服务以「尽力提供」为原则。

---

## 2. 合理使用

使用本在线服务时，你同意**不**进行以下行为：

1. **批量爬取**：以自动化脚本、机器人或类似方式大规模抓取、刷取服务或结果。
2. **转售 / 再分发最终文件**：禁止把「由本服务生成的最终文件」（如导出的 DXF / STEP）作为**独立产品**出售或再分发。（你对**自己的设计**拥有权利；本条限制的是把服务输出当作配件 / 数据产品转卖的行为。）
3. **绕过配额或验证码**：禁止规避、伪造或绕过每日配额、人机校验（Turnstile）等访问控制。

> 具体禁止清单与措辞**（待法务确认）**。

---

## 3. 配额与封禁

- 为保障服务稳定与成本可控，本服务对调用设置**配额**，例如：
  - 匿名（按 IP）：STP / 装配 **20 次 / 日**，模型下载 **20 次 / 日**（具体数值可能调整）。
  - 超出配额时，服务返回 **HTTP 429（Too Many Requests）**。
- 服务可启用**人机校验（Turnstile）**，且可**开关**；启用时需通过校验后方可调用。
- 对**违反 §2 合理使用**或明显滥用的行为，我们**有权限流或封禁**（按 IP / 账号 / 来源）。
