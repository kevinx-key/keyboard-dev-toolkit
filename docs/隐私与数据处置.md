# 隐私与数据处置

> 版本 v1.0（2026-10-11）· 面向用户 · 公开
> 适用范围：Keyboard Dev Toolkit（键盘配列编辑器 + PCB / 定位板自动生成）。
> 对应内部要求：§G-B8（隐私叙事修正）、§G-C7（数据处置政策）。
> 本页为产品说明，非法律意见；涉及法律责任的部分以正式法律文件为准。

---

## 1. 一句话总结：基础本地、高级云端

- **基础能力完全本地**：KLE 解析 / 渲染 / 编辑、矩阵分配、简单矩形 PCB 外框 / 单键轴孔 / 基础定位板、底棉矩形等，全部在你的浏览器 / 桌面设备内完成，**不联网**，可离线使用。
- **高级能力在云端**：碰撞体积干涉预警、FL / 板载卫星轴开孔与钢丝间距等高级 2D 几何，以及 STP 装配 / 3D 导出，需要联网，由 `https://starthock.com` 下的服务计算。

> 说明：早期文案中的「100% 本地 / 完全本地 / 离线可用」仅适用于**基础能力**。涉及高级几何与 STP 时，数据会离开你的设备，本文说明其处理方式。

---

## 2. 哪些功能不联网，哪些会上传数据

| 功能 | 是否联网 | 是否上传设计数据 |
|---|---|---|
| KLE 解析 / 渲染 / 编辑、12 Tab 面板 | 否 | 否 |
| 矩阵分配（`matrix-core` / `key-matrix`） | 否 | 否 |
| 简单矩形 PCB 外框 / 单键轴孔 / 基础定位板 | 否 | 否 |
| 底棉自定义矩形 | 否 | 否 |
| 碰撞体积干涉预警（热插拔 / MCU / Type-C 异形边界） | 是 | 是（设计快照） |
| FL / 板载卫星轴开孔、钢丝间距计算 | 是 | 是（设计快照） |
| 高精度 / 异形 DXF 导出 | 是 | 是（设计快照） |
| STP 装配 / 3D 导出 | 是 | 是（设计快照） |

- **仅使用基础功能时，不上传任何设计数据。**
- 触发高级 / STP 功能时，客户端才会向云端发送请求。

---

## 3. 上传内容最小化

上传的仅为**设计快照**，即复现该次计算所必需的最小输入：

- 布局坐标（各键的位置、尺寸、旋转等几何参数）；
- 本次导出的参数（如导出类型、加工参数、目标格式）。

**不包含**：账号个人信息、设备标识、通讯录、文件系统内容等与计算无关的数据。

> （待法务确认：如后续引入登录账户，需在本节补充账号相关字段的说明。）

## 4. 传输、存储与保留

- **传输加密**：客户端与云端之间全程使用 **HTTPS**。
- **结果缓存**：为降低重复计算成本，云端按**内容哈希**缓存计算结果（缓存键为设计快照 + 参数 + 引擎版本）。
- **保留期**：缓存结果的保留期**不超过 30 天**；到期后自动清理。
- **结果下载**：大文件（如 STEP）经对象存储的**预签名链接**下载，链接有有效期。

对上传的设计数据，我们承诺：

- **不外泄**给第三方（法律法规强制要求或你另行授权的除外）；
- **不用于训练**任何模型；
- **不转售**你的设计数据或由其生成的最终文件。

> 上述承诺的具体法律措辞与责任范围**（待法务确认）**。

## 6. 用户设计保密

你上传的是**你自己的商业设计**——对键盘厂商 / 设计师而言属于核心机密。我们对其**保密优先级等同自家资产**：访问受控、最小必要、仅用于本次计算与缓存。

---

## 7. 可选「仅基础模式」

如果你不希望任何设计数据离开设备，可选择**仅基础模式**：不联网，完全放弃高级几何与 STP 功能，只使用本地的配列编辑与基础 PCB / 定位板生成。

- 基础模式下的功能与隐私行为见 §2「否 / 否」各行。
- 离线环境下，高级 / STP 入口应处于禁用或不可用状态。
